dialect, localization, and spec-gated pipeline. Use `neohaskell-localizer` to
select the integration capability and `neohaskell-implementer` for `.hs` edits.

Canonical skills live in [.agents/skills](../.agents/skills/).
Run `./dev` commands from the repository root.
