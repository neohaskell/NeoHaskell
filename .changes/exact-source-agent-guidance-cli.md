## Summary

New projects include shared instructions for Codex and Claude. The CLI keeps their framework guide matched to the exact NeoHaskell revision used by the project's build files, including a local framework source override. If that guide cannot be fetched, the project still builds and the instructions show that guidance is unavailable. Existing instructions and edited skills stay as the developer wrote them.
