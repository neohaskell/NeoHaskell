## Summary

Framework users need no app changes. A trusted main-branch workflow now realizes and publishes the Linux CI and default shells and the macOS default shell to Cachix. Framework contributors can list local test jobs and run the documented ADR index check through the Nix-packaged `act` command. These CI and contributor-tool changes do not affect application behavior or public APIs.
