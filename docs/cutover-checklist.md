# Neo CLI cutover checklist

## Status

Retired.

This checklist described a monorepo cutover that depended on standalone installer releases and a clean-machine onboarding limit of 600 seconds. The project retired the installer and the timing requirement on 2026-10-22. Do not use the former release, archive, or rollback steps as current instructions.

[ADR-0072](decisions/0072-neo-cutover-and-onboarding-slo.md) preserves the former decision as history. The [NeoHaskell release workflow](../.agents/skills/neohaskell-release/SKILL.md) describes current release preparation.
