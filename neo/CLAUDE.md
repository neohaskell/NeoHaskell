# Neo CLI - Claude guide (`neo/**`)

Read [`AGENTS.md`](AGENTS.md). It is the single agent contract for the Rust Neo
CLI: the scope override (this is Rust, not NeoHaskell dialect), the working
environment, the test layers, the cross-component correctness gate, and the
error/output invariants. Detail lives in the repo-root `neo-cli-*` skills
(`neo-cli-localizer`, `neo-cli-implementer`, `neo-cli-testing`, `neo-cli-ide`).

There is no Claude-only rule for this tree; there is nothing here that `AGENTS.md`
does not already cover.
